# Demo script (grows with each phase)
Phase 1: open the Waterloo Demo Zone → note the provenance badges (Derived demand, Modeled DERs/capacity, Hypothetical project) → press Play at 100x to watch load move against the modeled 90 MW capacity → "Jump to peak" (78 MW, 12 MW headroom) → click the daily-peak overview to jump to another season.

Phase 2 (golden demo): click "Golden demo (20 MW)" -> the baseline was fine (0 hours over 90 MW); +20 MW data centre (Hypothetical) gives 268 constrained hours across 51 days (59 event windows), projected peak 98 MW, worst deficit 8.0 MW on 2025-06-24 -> press "Jump to peak" / click the worst window (14 h, 08:00-22:00) to replay -> use Prev/Next event -> resize the data centre (10 MW: 0 hours; 30 MW: 2,912 hours) -> Remove or Reset. Status reads "Constraint events detected"; flexibility is deliberately not evaluated until later phases.

Phase 3: with the golden scenario at the peak hour, open the DER agents panel -> 78 modeled agents (20 batteries, 14 EV fleets, 36 buildings, 8 solar clusters) -> potential at this hour is 4.3 MW against an 8.0 MW deficit (54%), 11.3 MW if everyone enrolled -> click an agent to inspect its state and day profile -> raise battery/EV participation and watch potential rise (nested populations) -> note solar shows 0 relief because it is already in the baseline. Nothing is dispatched yet.

Phase 4: golden scenario -> cursor sits inside the Jun 24 event (08:00-22:00) -> "Coordinate DERs" -> result: partially resolved (75.7 -> 67.3 MWh above capacity; worst 8.0 -> 6.4 MW; 16:00 drops from 98 to ~94 MW) -> world shows "optimized · was 98.0" and per-type dispatch (batteries 3.8 MW from 6 agents) -> inspect the before/after chart, dispatch-by-type bars and per-agent D/C/F/R/S/B strips -> raise participation to 100% in the DER panel and coordinate again (46.4 MWh; still partial: the population lacks energy for a 14 h event) -> set to 0% (unresolved). This is deliberately not a feasibility verdict; recommendations come later.

Phase 5-6 (agentic mode): golden scenario -> cursor inside the Jun 24 event -> switch DER Coordination to **Agentic** -> the request card reads Need 8.0 MW / 08:00-22:00 / incentive -> pick $120 (or $40, $80) -> "Broadcast flexibility request" -> watch 18 owner agents evaluate, offer, decline or counteroffer; some get "Physical validation failed" (e.g. insufficient usable energy), revise once, and are accepted -> market summary (requested / offered / validated / dispatched / remaining) -> before/after chart and world dispatch come from the OR-Tools clearing of validated offers -> click an owner to inspect its Modeled preferences, offers and validation -> "Replay from record" re-runs validation + clearing from the recorded actions (same result hash). Compare $40 (almost nobody offers) vs $120: participation emerges from owner economics, not a hard-coded curve. Still not a feasibility verdict.

Phase 7 (historical): golden scenario -> switch DER Coordination to **Historical** -> run $40, $80 and $120 (about 10 s each) -> comparison table: 268 constrained hours / 532.5 MWh before; after: 264 / 518 (almost nobody offers), 190 / 384, 88 / 153 (42 of 59 events resolved) -> inspect a scenario: whole-history before/after, DER contribution (at $120 batteries deliver 76%), by year, by season (all summer/fall: the heat-driven peaks), by severity (severe events stay partial) -> click an event in the list to jump there: the world shows "optimized · was …" -> open Verification (hours/energy reconcile with a direct scan of all 43,824 hours; no violation created elsewhere). Say clearly: 0 LLM calls, Modeled owner behavior, user-selected incentives, not a recommendation and not a feasibility verdict.
